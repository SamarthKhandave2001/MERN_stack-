1. What's the difference between undefined and null?
undefined is a special value JavaScript assigns automatically when:
A variable is declared but not set to any value
A function doesn't return anything explicitly
When accessing a nonexistent property of an object
The JavaScript engine generates undefined automatically

null is an assignment value, set deliberately to represent "no value", "empty", or the intention for something to be blank

Unlike undefined, JavaScript never assigns null automatically

What does the && operator do?
The logical AND operator (&&) evaluates expressions from left to right
It returns the first value that is falsy (false, 0, "", null, undefined, NaN)
If all values are truthy, it returns the last value
This is called "short-circuit evaluation"—it stops as soon as it hits a falsy value

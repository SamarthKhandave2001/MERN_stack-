//MCQ question
Which of the following methods can add an element to the end of an array?
ANS: Push()
What does the pop() method do in JavaScript arrays?
ANS: Remove element from the end of an array.
Which method is used to remove the first element of an array?
ANS: Shift()
What is the output of the following code?
let arr = [1, 2, 3];
arr.push(4);
arr.pop();
console.log(arr);
ANS : [1,2,3] 

How can you combine two arrays in JavaScript?
ANS: arr1.concat(arr2)

Which of the following will correctly reverse an array?

let arr = [1, 2, 3, 4, 5];
ANS: arr.reverse().

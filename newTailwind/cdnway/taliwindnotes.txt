1. What is Tailwind CSS?

Tailwind CSS is a utility-first CSS framework that provides pre-defined utility classes to build custom designs directly in HTML without writing custom CSS.

What does “utility-first” mean?

Instead of writing custom CSS classes, you use small utility classes like:

<div class="bg-blue-500 text-white p-4 rounded-lg"></div>

What are the advantages of Tailwind?

Faster development

No context switching between HTML & CSS

Highly customizable

Small production build (with Purge)

Responsive design built-in

What is Tailwind configuration file?

tailwind.config.js

Used for:

Custom colors

Custom spacing

Extending themes

Adding plugins

command to run tailwind- npx tailwindcss -i ./src/input.css -o ./src/output.css --watch

What is Purge in Tailwind?

Removes unused CSS from production build to reduce file size.
